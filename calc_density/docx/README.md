# Гамма-выборка и три метода разбиения

## Запуск

Из каталога `calc_density` запустите `python main.py`. Нужны Python 3.10 или новее, NumPy, SciPy и Matplotlib. По умолчанию программа выполняет по 100 повторений для k=1, k=8, [1, 8] и [2, 4] при θ=1, N=20, 100, 4000 и α=0, 0.2, 0.5, 1, 2. Используются `N_ref=20` и `seed=20261115`. Полный запуск сохраняет выборки для всех комбинаций, поэтому объём результатов зависит от N и числа повторений. Параметры можно изменить в сигнатуре `main()` или передать при вызове.

```python
from main import main

directory = main(
    massive_k=[1, 8, 15],
    theta_values=(1,),
    N_values=(20, 100, 500, 1000),
    N_ref=20,
    alpha_values=(0, 0.2, 0.5, 1, 2),
    koef=0.7,
    replays=1000,
    seed=20261115,
)
print(directory)
```

При `massive_k=None` каждое значение из `k_values` задаёт отдельный эксперимент. Плоский список `massive_k` задаёт одну смесь. Вложенные списки, например `[[1, 8], [2, 4, 6]]`, задают несколько независимых групп. При опорном размере `N_ref` квоты распределяются поровну, остаток получают первые компоненты. Для каждого N квоты масштабируются пропорционально. Например, при трёх компонентах и `N_ref=20` квоты (7, 7, 6) переходят в (35, 35, 30) при N=100. Если для заданного N точные целые квоты невозможны, программа выдаёт ошибку. Чтобы получить равные веса в смеси из трёх компонентов, задайте `N_ref` и все N кратными трём.

`main.py` запускает расчёты, передаёт данные в `plotting.py` и передаёт рисунки и результаты в `report.py`. Модель и эксперимент реализованы в `calc.py`. Графики возвращаются как объекты Figure. Папки и файлы результатов создаёт `report.py`.

## Расчёт областей

Пусть F — CDF чистого гамма-распределения. Для смеси `F(x) = Σᵢ(nᵢ/N) Fᵢ(x)`, где `Fᵢ` — CDF компоненты, а `nᵢ` — её квота. Для границ a и b считаем доли наблюдений в областях `x ≤ a`, `a < x < b`, `x ≥ b`. Теоретические вероятности областей равны `F(a)`, `F(b) − F(a)` и `1 − F(b)`.

1. **Площади под плотностями экстремумов.** Для выборки размера `N_ref` границы удовлетворяют `P(min ≤ a) = koef` и `P(max ≥ b) = koef`. Для одного k при `q = 1 − (1 − koef)^(1/N_ref)` получаем `a = F⁻¹(q)` и `b = F⁻¹(1 − q)`. Для смеси CDF максимума равна `∏ᵢFᵢ(x)^nᵢ`, а вероятность `P(min > x)` равна `∏ᵢ(1 − Fᵢ(x))^nᵢ`. Эти равенства решаются численно. Площади относятся к распределениям экстремумов по всей оси. Вероятности областей относятся к отдельным элементам выборки. Например, при k=8, θ=1, N=20, koef=0.7 границы равны примерно 4.11723 и 12.84920, а вероятность каждого хвоста для отдельного элемента — 0.05842.
2. **Равные вероятности.** Границы — квантили 1/3 и 2/3 исходной CDF. Каждая область имеет теоретическую вероятность 1/3.
3. **Равные интервалы по x.** Расчётный диапазон от 0 до квантиля 0.9999 исходной CDF делится на три равные части. Его верхняя точка задаёт ширину интервалов. Наблюдения правее диапазона тоже попадают в правую область.

Все три пары границ рассчитываются один раз по чистой модели и применяются при каждом N и α. График экстремумов показывает плотности для `N_ref` в диапазоне, охватывающем не менее 99.99% массы максимума. При k<1 плотность может стремиться к бесконечности в нуле, поэтому она строится по положительным точкам. Первый метод требует `0 < a < b`. При пересечении границ нужно увеличить `N_ref` или уменьшить `koef`.

## Шум и показатель ошибки

В каждом повторении генерируется чистая выборка X и стандартный нормальный шум Z. Для каждого α получаем `Y = max(0, X + αZ)`. При сравнении α меняется только множитель при Z. Все три метода получают одинаковые наблюдения Y, а их границы и теоретические вероятности рассчитываются по чистой модели.

Для каждого метода и повторения `D = Σⱼ ((pⱼ − p̂ⱼ) / pⱼ)²`, где `p̂ⱼ = nⱼ/N`. В отчёте есть средняя D и её стандартное отклонение по повторениям (делитель — число повторений). Объединённая D использует доли по всем повторениям сразу.

Для обнаружения тенденции по N используется математическое ожидание `E[D]=A(α)+B(α)/N`. Пусть `wᵢ` — доля компоненты, `qᵢⱼ` — её вероятность попасть в область j после добавления шума, а `qⱼ=Σᵢ wᵢ qᵢⱼ`. Тогда:

- `A=Σⱼ ((qⱼ − pⱼ)/pⱼ)²` описывает систематическое изменение вероятностей из-за шума.
- `B=Σⱼ Σᵢ wᵢ qᵢⱼ(1 − qᵢⱼ)/pⱼ²` описывает случайный разброс при фиксированных квотах.

Значения `qᵢⱼ` получаем интегрированием гамма CDF по распределению Z. При положительной левой границе все значения, обрезанные до нуля, остаются в левой области. При α=0 выполняется A=0 и ожидание убывает как 1/N. При шуме ожидание убывает к A. Измеренное среднее может колебаться. Планки на графиках показывают приближённый 95% интервал `среднее ± 1.96 × SE`, где SE рассчитывается по выборочному стандартному отклонению, делённому на корень из числа повторений. При одном повторении SE отсутствует.

## Результаты и проверки

В `results/k_…/alpha_…/N_…` находятся теоретические графики, гистограммы, Markdown-отчёт и CSV для конкретных параметров. Строки в `replays_….csv` содержат счётчики трёх методов для каждого повтора. В `chi_squared_comparison_….csv` указаны доли и вклад каждой области в объединённую D. В `samples_….csv` есть компонента k и обе версии каждого наблюдения.

В `results/k_…/alpha_…` лежат сравнения по N. Файлы `comparison_three_methods_…` показывают объединённую D, а `comparison_by_N_…` содержат среднюю D, её неопределённость и теоретическую кривую.

В `results/k_…/comparison_theta_….csv` каждой паре α и N соответствует одна строка со столбцами `alpha`, `N`, `method_1_D`, `method_2_D` и `method_3_D`. Для всех трёх методов указана D по объединённой выборке. В корне `results/` пары файлов `comparison_all_groups_theta_…_N_….png` и `.csv` сравнивают тот же коэффициент при фиксированном N. По горизонтали отложен α, каждой группе k соответствует своя линия, а трём методам соответствуют отдельные панели. Пары файлов с суффиксом `_alpha_…` показывают коэффициент по N при фиксированном α. Полная таблица `comparison_all_groups_theta_….csv` содержит также среднюю и ожидаемую ошибки.

```sh
python -m unittest discover -s test -v
python -m test.study
```

Команда `python -m test.study` повторяет исследование на тех же четырёх группах и проверяет убывание E[D] по N и согласие средних с рассчитанным ожиданием. Отчёт и сводные таблицы проверки сохраняются в `results/validation/run_…`.
